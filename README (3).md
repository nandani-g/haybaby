# Pip · Junior Dream Engineer (Track 1)

Portfolio for Pip, the skull baby of the Midnight Nursery.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
Push to a public GitHub repo (commits must be between 17–19 Oct 2026), then connect to Vercel / Netlify / GitHub Pages.

## Features so far (Tier 1 + some bonus)
- Eyes follow cursor / touch
- Day / night toggle (changes palette and Pip's mouth)
- Scroll-driven story scenes
- Mute toggle (sound off by default)
- Lullaby music box (Web Audio), nightlights, block-stacking toy
- Sparkle cursor trail, hit counter odometer
- Hidden Easter egg: tap the yellow star on Pip's cap 5 times
